# Xylella Research Repository

Этот репозиторий предназначен для материалов по исследованию бактерии **Xylella**, а не для программного кода.

## Структура

- `datasets/` — датасеты для исследований.
- `research-materials/` — исследовательские материалы и связанные документы.
- `comments/` — комментарии и пояснения к материалам и датасетам.
